# Portfolio Website

This repository contains a professional static portfolio website for an undergraduate student looking for internships and entry-level software roles.

## Files
- `index.html` — page structure and content
- `styles.css` — responsive styles and layout
- `script.js` — mobile navigation toggle

## Customize
Update the placeholder text with your name, email, project details, skills, and education.

## Run locally
1. Open `index.html` in your browser.
2. Or use a local server:
   - `npx serve .`
   - `python -m http.server 8000`

## Deploy
### GitHub Pages
1. Create a GitHub repository and push this folder.
2. In repo settings, enable **Pages** from the `main` branch and `/ (root)` folder.
3. Visit `https://<your-username>.github.io/<repo-name>/`.

### Vercel or Netlify
1. Connect your GitHub repository.
2. Select the project root.
3. Deploy the site as a static website.

## Notes
- Replace `your.email@example.com` with your real email.
- Add your actual LinkedIn profile and project links.
- Enhance the design further with your personal branding.
